דשבורד ניהול

אזור פרטי לבעל האתר. נתוני התנועה עצמם זמינים רק לאחר התחברות לחשבון Google Analytics שיש לו הרשאה לנכס של האתר.

פתיחת Google Analytics
חשוב: האתר משתמש ב־GA4 עם מזהה המדידה G-4WPV84ES2X. דף סטטי לא יכול להחזיק סיסמה או אסימון API בצורה בטוחה; אל תוסיף כאן פרטי התחברות. כדי שרק אתה תוכל לפתוח את הדף, הפעל Password Protection / Access Control אצל ספק האחסון.
